Search engines

Your links

They appear after the team’s. The logo comes from the address.

Learning

The page learns which sites you use and reshapes itself around them. What you use that isn’t listed shows up under Frequent, links you never open fold into Rarely opened, and links whose address stops existing disappear. It learns from what you open here, and with the Mandy Start extension from everything you browse. All of it stays in this browser.

Install for Zen or Firefox Chrome and others

In Zen, set xpinstall.signatures.required to false in about:config before installing.

Team links

Everyone sees the same team links. To change them, edit js/team.js and push to main.
